# 🍡 Financial Dashboard - ร้านลูกชิ้น 4 สาขา (กันยายน 2569)

ระบบสรุปและวิเคราะห์ผลประกอบการรายรับ-รายจ่าย ประจำวัน (วันที่ 1 - 20 กันยายน) ของร้านลูกชิ้นทั้ง 4 สาขา พร้อม Dashboard แบบ Interactive ฉบับ Redesign ใช้งานง่าย แบ่งหมวดหมู่อย่างเป็นระบบ

---

## 🚀 ฟังก์ชันหลักของ Dashboard (ฉบับ Redesign)

1. **ระบบ Tab Navigation 4 มุมมองหลัก**:
   - 📊 **ภาพรวมเดือนปัจจุบัน (ก.ย. 69)**: สรุปยอดขาย 20 วันแรก, ค่าใช้จ่ายดำเนินงาน, ค่าเช่าคงที่, กราฟแนวโน้มรายวัน (Daily Trend), สัดส่วนยอดขาย (Donut Chart) และตารางแยกรายวัน
   - 📅 **สรุปภาพรวมปี 2569 (ม.ค. - ก.ย.)**: รายงานยอดขายสะสมทะลุ 1.08 ล้านบาท, All-Time High เดือน เม.ย. สงกรานต์ (฿205k), กราฟเปรียบเทียบรายเดือน 9 เดือน, และตารางวิเคราะห์เปรียบเทียบ 4 สาขา
   - 🏪 **เจาะลึกประวัติรายสาขา (Branch Deep Dive)**: สลับเลือกดูเฉพาะสาขาที่ต้องการ (สาขา 1 🏆, สาขา 2, สาขา 3 🥈, สาขา 4 🚀 ทะลุ 2 แสนบาท) พร้อมกราฟประวัติรายเดือน บันทึกค่าเช่า และหมายเหตุสำคัญ
   - 🎯 **เครื่องมือวางแผนเป้าหมาย (Target Simulator)**: ระบบคำนวณเป้ายอดขาย 10 วันที่เหลือ (21 - 30 ก.ย.) ปรับเป้ากำไรด้วย Slider พร้อมกระจายเป้าหมายรายวันตามศักยภาพของแต่ละสาขา

2. **ระบบสวิตช์ค่าเช่าคงที่ (Rent Toggle)**:
   - สามารถเปิด/ปิดการคิดค่าเช่าคงที่ได้ทันที เพื่อดูกำไรจากการดำเนินงานจริง (Operating Profit) เปรียบเทียบกับกำไรสุทธิหลังหักค่าเช่า

3. **กราฟ Interactive SVG พร้อม Tooltip ละเอียด**:
   - ชี้ดูรายละเอียดยอดขาย รายจ่าย และผลกำไรสุทธิในแต่ละวันและแต่ละเดือนได้ทันที

4. **ระบบค้นหาและดาวน์โหลดข้อมูล (Export CSV)**:
   - ค้นหาวันที่ในตารางรายวันได้แบบ Real-time
   - ปุ่มดาวน์โหลด CSV แยกตามมุมมอง (รายวัน 4 สาขา, สรุปทั้งปี 2569, และประวัติรายสาขา)

## 📁 โครงสร้างไฟล์
- `index.html` / `dashboard.html`: หน้า Interactive Dashboard หลัก (รองรับทั้ง Desktop, Mobile และ GitHub Pages)
- `สรุปยอดรายรับรายจ่าย_4สาขา.xlsx`: ไฟล์ตารางคำนวณ Excel / Google Sheets
- `สรุปภาพรวมปี_2569.csv`: ข้อมูลสรุปผลประกอบการรายเดือนปี 2569
- `สรุปภาพรวม_4สาขา.csv`: ตารางสรุปภาพรวมผลประกอบการ
- `รายงานรายวัน_4สาขา.csv`: ข้อมูลรายวัน 20 วันแรก ก.ย. 2569
- `สรุปประวัติย้อนหลัง_สาขา1.csv`, `สาขา3.csv`, `สาขา4.csv`: ข้อมูลประวัติย้อนหลังรายสาขา

## 🌐 การเปิดใช้งานออนไลน์ผ่าน GitHub Pages
1. ไปที่แท็บ **Settings** ของ Repository
2. เลือกเมนู **Pages** (ทางซ้ายมือ)
3. ภายใต้หัวข้อ **Build and deployment**:
   - Source: Deploy from a branch
   - Branch: main / Folder: / (root)
4. กด **Save** รอประมาณ 1 นาที จะได้ลิงก์เปิดดูเว็บไซต์ Dashboard แบบออนไลน์ทันที
