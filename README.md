   - 🏪 **เจาะลึกประวัติรายสาขา (Branch Deep Dive)**: สลับเลือกดูเฉพาะสาขาที่ต้องการ (สาขา 1 🏆, สาขา 2 🎯, สาขา 3 🥈, สาขา 4 🚀) พร้อมกราฟประวัติรายเดือน บันทึกค่าเช่า และหมายเหตุสำคัญ
   - 📈 **วิเคราะห์เจาะลึกธุรกิจ (Business Insights ✨)**: 4 มิติเพิ่มกำไร (สัดส่วนเงินสด vs เงินโอน, โครงสร้างต้นทุนและสต็อก, แพทเทิร์นวันยอดขายพีคสุดสัปดาห์, และจุดคุ้มทุนรายวัน BEP แต่ละสาขา)
   - 🎯 **เครื่องมือวางแผนเป้าหมาย (Target Simulator)**: ระบบคำนวณเป้ายอดขาย 8 วันที่เหลือ (23 - 30 ก.ย.) ปรับเป้ากำไรด้วย Slider พร้อมคำนวณแบบ Real-time

2. **ระบบสวิตช์ค่าเช่าคงที่ (Rent Toggle)**:
   - สามารถเปิด/ปิดการคิดค่าเช่าคงที่ได้ทันที เพื่อดูกำไรจากการดำเนินงานจริง (Operating Profit) เปรียบเทียบกับกำไรสุทธิหลังหักค่าเช่า

3. **กราฟ Interactive SVG พร้อม Tooltip ละเอียด**:
   - ชี้ดูรายละเอียดยอดขาย รายจ่าย และผลกำไรสุทธิในแต่ละวันและแต่ละเดือนได้ทันที

4. **ระบบค้นหาและดาวน์โหลดข้อมูล (Export CSV)**:
   - ค้นหาวันที่ในตารางรายวันได้แบบ Real-time
   - ปุ่มดาวน์โหลด CSV แยกตามมุมมองครบทั้ง 6 รูปแบบ (รวม CSV ประวัติย้อนหลัง สาขา 2)
