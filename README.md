## 🛠️ 9. คู่มือสคริปต์สำหรับการ Push ข้อมูลขึ้น GitHub (Deployment Guide)

เมื่อไม่มีคำสั่ง `git` ในเครื่อง ให้ใช้ PowerShell Script สั่งงานผ่าน GitHub REST API โดยมีสคริปต์พร้อมใช้งานในโฟลเดอร์ Scratch:
- **สคริปต์ Push ข้อมูล:** `C:\Users\dewsun818\.gemini\antigravity\brain\cad7cc68-417e-424c-8ff3-0f8f75fe1cd0\scratch\push.ps1`
- **สคริปต์ตรวจสถานะ Pages:** `C:\Users\dewsun818\.gemini\antigravity\brain\cad7cc68-417e-424c-8ff3-0f8f75fe1cd0\scratch\check_status.ps1`

ตัวอย่างโค้ดสคริปต์ Push ผ่าน REST API:

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$token = "<GITHUB_PERSONAL_ACCESS_TOKEN>"
$repo = "dewsun8-18/dew"
$headers = @{
    "Authorization" = "Bearer $token"
    "Accept"        = "application/vnd.github.v3+json"
    "User-Agent"    = "PowerShell-Script"
}

$workDir = (Get-Location).Path
$files = Get-ChildItem -Path $workDir -File | Where-Object {
    $_.Extension -eq ".csv" -or $_.Name -in @("dashboard.html", "index.html", "README.md")
}

foreach ($f in $files) {
    $encodedName = [System.Uri]::EscapeDataString($f.Name)
    $url = "https://api.github.com/repos/$repo/contents/$encodedName"

    $sha = $null
    try {
        $resp = Invoke-RestMethod -Uri $url -Headers $headers -Method Get
        $sha = $resp.sha
    } catch {}

    $bytes = [System.IO.File]::ReadAllBytes($f.FullName)
    $base64Content = [System.Convert]::ToBase64String($bytes)

    $body = @{
        message = "feat: update $($f.Name)"
        content = $base64Content
        branch  = "main"
    }
    if ($sha) { $body["sha"] = $sha }

    $jsonBody = $body | ConvertTo-Json -Compress
    $bodyBytes = [System.Text.Encoding]::UTF8.GetBytes($jsonBody)
    $putResp = Invoke-RestMethod -Uri $url -Headers $headers -Method Put -Body $bodyBytes -ContentType "application/json; charset=utf-8"
}
```
